## 🚑 EMS Medical Extension - 21 Jump Click

Merci à tous les EMS qui utilisent l'extension au quotidien ! Voici ce que la v0.12.0 embarque :

### 🆕 Nouveautés

- 🖋️ **Option Détatouage** - nouveau groupe dans Notes Internes avec champs Nombre, Zone et Facture $. Génère automatiquement la VC à +24h.
- 🧪 **Champ Taux g/L pour Coma éthylique** - saisie du taux d'alcool directement dans le panneau de complétion.
- ⌨️ **Fermeture avec Escape** - la sidebar Bilan se ferme maintenant avec la touche Échap.
- 🎨 **Refonte graphique complète** - nouveau design du panneau Completion et de la sidebar Bilan : palette harmonisée, scrollbar stylisée, transitions fluides, boutons fixés en bas.
- 📍 **Panneau positionné à droite** - le panneau Completion s'ouvre à droite du dialog, sans superposer le formulaire.

### ✨ Fonctionnalités

- 🩺 **Complétion automatique de rapport** - pré-remplissage intelligent des champs avec gestion des incompatibilités dynamiques.
- 🗂️ **Bilan Anatomique interactif** - sidebar multi-zones avec stack de pathologies et injection groupée (Examens + Traitements).
- 📅 **Remplissage rapide des dates** - boutons VM / DDS / VC avec calcul automatique de la date de contrôle.
- 🏷️ **Chips Infos ok / Infos pas ok** - gestion mutex directement dans le champ urgence MUI.
- 🩺 **Bouton VC (Visite de Contrôle)** - génère automatiquement un nouveau rapport de suivi depuis le détail d'un rapport existant.
- 🎲 **Randomizer Groupe Sanguin** - attribution aléatoire parmi les 8 groupes dans l'examen médical.
- ⚙️ **Popup de configuration** - sélection hôpital (BCES / LSES), ZIP par défaut, raccourcis dispatches.
- 🌐 **Support Chrome & Firefox** - Manifest V3, polyfill intégré.
- 🔔 **Page de bienvenue & bannière d'épinglage** - guide visuel à la première installation.
- ⚡ **Variante Lite** - build allégé sans les modules lourds.

### 📦 Installation

#### 1. Téléchargement et Préparation
* Téléchargez le fichier `.zip` correspondant à votre navigateur :
  * Pour **Chrome** : `ems-medical-extension-21jc-v0.12.0-chrome.zip` ou `ems-medical-extension-21jc-v0.12.0-chrome-lite.zip`
  * Pour **Firefox** : `ems-medical-extension-21jc-v0.12.0-firefox.zip` ou `ems-medical-extension-21jc-v0.12.0-firefox-lite.zip`
* Placez le fichier dans le dossier de votre choix (par exemple, vos Documents).
* Faites un **clic droit** sur le fichier `.zip` et choisissez **Extraire tout** (ou *Extraire ici*). Un dossier non compressé contenant les fichiers de l'extension va se créer.

---

#### 🌐 Sur Google Chrome
1. Ouvrez Chrome et allez dans le menu des **Extensions** (en tapant `chrome://extensions/` dans votre barre d'adresse).
2. Activez le **Mode développeur** (l'interrupteur situé en haut à droite).
3. Cliquez sur le bouton **Charger l'extension non empaquetée** (en haut à gauche).
4. Sélectionnez le dossier complet que vous venez d'extraire. L'extension est installée !

---

#### 🦊 Sur Mozilla Firefox
1. Ouvrez Firefox et allez sur la page de débogage (en tapant `about:debugging` dans votre barre d'adresse).
2. Cliquez sur **Ce Firefox** dans le menu de gauche.
3. Cliquez sur le bouton **Charger un manifeste temporaire...** (dans la section *Extensions temporaires*).
4. Naviguez dans le dossier extrait pour Firefox, ouvrez-le, puis sélectionnez le fichier nommé **`manifest.json`**. L'extension est prête !

> ⚠️ **Note pour Firefox :** Les extensions chargées de cette manière sont temporaires et s'enlèvent automatiquement à la fermeture du navigateur. Pour éviter cela, il faudra à l'avenir passer par un fichier `.xpi` signé ou le store d'extensions.
